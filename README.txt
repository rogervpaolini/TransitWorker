Transfer Assistant
===================

Standalone responsive HTML/CSS/JS website package.

Files:
- index.html — homepage and full article
- about.html — About page
- privacy.html — Privacy Policy page
- contact.html — Contact page
- style.css — Matrix-inspired visual system and responsive layout
- script.js — code-rain animation, live clock, active section indicators, and contact form confirmation

Open index.html directly or deploy the folder to any static host.
